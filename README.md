# VisionAI - General Image Recognition & Explainability App

An interactive web application built with **Streamlit** and **TensorFlow (MobileNetV2)** that classifies everyday images and generates **Grad-CAM attention heatmaps** to explain what the AI is focusing on.

## Features
- **Instant Object Recognition**: Predicts top categories with confidence scores.
- **AI Explainability**: Visualizes AI attention using Grad-CAM heatmaps.
- **Prediction History & Analytics**: Logs recent scans and tracks session metrics.
